## 📌 Project Overview

This project focuses on analyzing **e-commerce sales data** and transforming cleaned data into meaningful business insights using **Excel, Python, Pandas, Matplotlib, Seaborn, and Tableau**.

The project follows a complete data analytics workflow:

> **Data Cleaning → Data Analysis → Visualization → Insights → Dashboard**

The objective is to understand sales performance, product performance, customer behavior, regional sales, payment preferences, and profitability.

---

## 🎯 Project Objectives

The main objectives of this project are:

- 📊 Analyze overall sales and profit performance
- 🏆 Identify the highest-performing product categories
- 🛍️ Find the top-selling products
- 📅 Analyze monthly sales trends
- 🗺️ Compare sales across different states
- 👥 Understand customer types
- 💳 Analyze payment methods
- 👤 Analyze sales by age groups
- 🎯 Study the relationship between discounts and profit
- 💰 Analyze the relationship between sales and profit
- 📈 Create meaningful data visualizations
- 📊 Develop a Tableau dashboard
- 💡 Generate insights to support business decisions
